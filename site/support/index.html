Support

Most problems are found by one command. Start there.

Run the health check

anynotate doctor

It checks the install, your PATH, the background service, the bridge, its token, the Chrome helper, the agent hooks and the retention setting, and says what to fix. It exits with an error only when something required is broken.

Install, update, remove

Install with the one-line command on the home page. After that:

anynotate update --dry-run     # show what an update would do
anynotate update               # install the latest release and restart the bridge
anynotate uninstall --dry-run  # show what would be removed
anynotate uninstall            # add --purge to delete ~/.anynotate (your notes) too

Re-running anynotate install is always safe: it repairs the setup and restarts the bridge.

Common problems

The extension says the bridge is not running

Run anynotate doctor. If the bridge or its service is down, run anynotate install to set it up again and restart it. The bridge listens on 127.0.0.1 port 47291; if another program already uses that port, the bridge cannot start.

The extension is not allowed to talk to the bridge

The bridge only accepts the extensions on its allow-list. The Chrome Web Store version is allowed by default with bridge 0.4.1 or later; run anynotate update. For a build you loaded yourself, copy its id from chrome://extensions and run:

anynotate origin add chrome-extension://<id>
anynotate install

The second command restarts the bridge and updates the Chrome helper so it picks up the change. anynotate origin list shows the allow-list.

The extension cannot reach the Anynotate helper

The extension gets the bridge's token from a small helper that anynotate install registers with Chrome, Edge, Brave and Chromium. If you installed the browser afterwards, or deleted ~/.anynotate/token, run anynotate install again.

anynotate: command not found

On macOS and Linux the binary goes to ~/.local/bin. If that folder is not on your PATH, add this line to your shell profile (for example ~/.zshrc or ~/.bashrc) and open a new terminal:

export PATH="$HOME/.local/bin:$PATH"

On Windows, the installer adds the binary's folder to your user PATH; open a new terminal window to pick it up.

My agent did not receive the notes

For Claude Code and Codex, notes sent to a session arrive with your next prompt in that session. In a herdr pane they are typed in once the agent is idle. Any other agent can read the newest notes with anynotate annotations latest or from ~/.anynotate/inbox/latest/README.md. anynotate annotations lists the recent ones.

Still stuck?

Open an issue on GitHub with the output of anynotate doctor and your operating system. Check the output for anything you would rather not share before posting.

Found a security problem? Please don't open a public issue; report it privately as described in SECURITY.md.
