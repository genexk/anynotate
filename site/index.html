How it works

From your page to your agent, on your machine

The extension hands your notes to a small local helper, the bridge, which delivers them to the session you pick.

Your computer
  1. Your browser Highlight, pick, write a note
  2. notes, page text, screenshot
  3. Anynotate bridge Runs locally on 127.0.0.1
  4. delivered to the session you pick
  5. Your AI agent session Claude Code, Codex or a herdr pane
Install

Two steps, about a minute

No account, no administrator rights.

  1. 1

    Install the bridge

    Paste one line into a terminal. It checks the download, starts the bridge in the background and connects your agents.

    curl -fsSL https://github.com/genexk/anynotate/releases/latest/download/install.sh | sh
    irm https://github.com/genexk/anynotate/releases/latest/download/install.ps1 | iex
  2. 2

    Add the Chrome extension

    Works in Chrome, Edge, Brave and Chromium.

    Chrome Web Store Coming soon

Works great with herdr

Run your agents in herdr? Add the Anynotate plugin (herdr 0.9.0 or later, macOS and Linux; Windows support for the plugin is coming). It installs the bridge too if you skipped step 1.

herdr plugin install genexk/anynotate/integrations/herdr
  • Inbox popup. Browse, read, send or delete your notes without leaving herdr.
  • Send to this pane. One key types the latest notes into the focused agent.
  • Status and links. A health check as a herdr notification, and Ctrl-click a note's path to open it.

Key bindings and details

Use it

Three tiny steps

  1. 1

    Start

    Press Alt+Shift+A on any page.

    On a Mac: ⌥⇧A

  2. 2

    Annotate

    Highlight text, or pick an element or drag a region with the crosshair or Alt+Shift+E. Write a note.

    Optionally tag it: explain, change or approve.

  3. 3

    Send

    Pick a session and press Send.

    Your agent gets every note with its context.

Features

Everything your agent needs to understand you

  • Numbered highlights

    Every note is numbered on the page until you send it, readable on light and dark pages.

  • Pick or select by keyboard

    Point at an element with Alt+Shift+E for its HTML, or select text with Shift and the arrow keys.

  • Mark a region

    Drag a box over a chart, canvas or blank space; the crop is just that box.

  • Intent tags

    Mark a note as explain, change or approve so the ask is clear.

  • Screenshot crops

    A crop of what you pointed at is captured when you write the note.

  • Send anywhere

    One list of herdr panes and Claude Code or Codex sessions, plus one 📥 Inbox any agent or MCP app reads.

  • Nothing lost

    Unsent notes stay in your browser; a note whose text left the page is still sent, with its crop.

  • Live pages

    Notes stay put through ticking values, re-rendered lists and hash routes; Scroll to finds one off screen.

  • Frames and embeds

    Annotate inside frames, including other sites' after one Allow, such as AI chat artifacts.

  • Tidy inbox

    Delivered notes are cleaned up after 30 days. You choose the period.

  • Every desktop

    Installers and a background service on macOS, Linux and Windows; Chrome, Edge, Brave and Chromium.

  • Open source

    The bridge, CLI and protocol are on GitHub for anyone to read.

Private by design

  • The extension sends nothing off your computer.
  • Your notes go only to the local bridge and the agent you choose.
  • Password, card and one-time-code fields are covered in screenshots and blanked in captured text.
  • The panel is hidden from the page's own scripts.
  • No accounts, no analytics, no tracking.

Your agent may pass what it reads to its own model provider, as it does with anything you give it. Read the privacy policy

Troubleshooting

Something not working?

Only needed if there are issues.

Run the health check, or update

This checks the install, the bridge, the Chrome helper and the agent hooks, and tells you what to fix:

anynotate doctor

Get the latest release and restart the bridge:

anynotate update

Common problems and fixes are on the support page.
