Point at a web page, tell your agent what you mean

Anynotate is a Chrome extension plus a small local helper. You highlight text or pick an element on any page, write a note, and send it to an AI coding session already running on your computer, such as Claude Code, Codex, or any agent in a herdr pane. The agent gets your notes together with the page text, the element's HTML and a screenshot, so it sees what you saw. The extension and bridge send nothing to the developer or any third party; your notes go only to the AI agent you choose, which may pass them to its own model provider.

1. Install the bridge

The bridge is the local helper the extension talks to. One command installs it; no administrator rights needed.

macOS and Linux
curl -fsSL https://github.com/genexk/anynotate/releases/latest/download/install.sh | sh
Windows (PowerShell)
irm https://github.com/genexk/anynotate/releases/latest/download/install.ps1 | iex

The installer checks the download against the release checksums, starts the bridge as a background service and sets up the Chrome helper and agent hooks. See the README for exactly what it writes.

2. Add the extension

The Anynotate extension for Chrome is coming soon to the Chrome Web Store.

3. Check it works

Run this any time something seems off. It checks the install, the bridge, the Chrome helper and the agent hooks, and tells you what to fix.

Health check
anynotate doctor

More help is on the support page.

Open source

The bridge, CLI and protocol are open source on GitHub (AGPL-3.0; the protocol package is Apache-2.0). Read the privacy policy to see how your data is handled: in short, it never reaches the developer.
